# Feature Localization Contract Checklist

For every future Operator-visible feature:

- Feature ID declared.
- Operator assets declared.
- English name and definition supplied.
- Arabic (`ar-IQ`) name and definition supplied.
- User actions declared with English and Arabic labels.
- Stable keyed localization used.
- Arabic values supplied for all UI keys.
- RTL layout considered.
- Technical identifiers remain LTR where required.
- Core CI passes `TestFeatureLocalizationContract`.
