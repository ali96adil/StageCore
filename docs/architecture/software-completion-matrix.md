# StageCore software completion matrix

Reviewed on `integration/stagecore-rc`: Issue #486 and child Issues #487–#513,
the current source and tests, and the open PRs listed in
[`related-component-qualification-matrix.md`](related-component-qualification-matrix.md).
The latest local/remote SHAs, pending commits, exact-head CI state and recent
verification are recorded in the dated campaign checkpoints. This matrix keeps
software evidence separate from installed application and physical qualification.
Issue status and software status are separate: an open issue can have
implemented code, and a passing software test does not imply physical
qualification.

**Status key:** `Implemented` means the requested behavior is present in code
and has relevant automated checks; `Partial` means code exists but a stated
software acceptance condition remains; `Open` means a reproducible software
gap or missing implementation remains. Hardware is called out separately.
