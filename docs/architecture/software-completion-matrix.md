software acceptance condition remains; `Open` means a reproducible software

## Integration and resilience coverage

Existing tests cover substantial network, ACK, retry, duplicate, session,
snapshot, project-scope, blackout and revocation behavior in the Cue Engine,
Runtime Control, device assignment, Companion, Camera Relay and StageAudio
packages. The campaign must close the remaining explicit fault scenarios with
isolated regressions: ACK delay/loss and reconnect per adapter, duplicate
delivery policy, snapshot/project mismatch, session loss, access revocation
during delayed GO, restart and SQLite/Vault integrity, offline operation, and
failed-update rollback. Tests must use fake/simulated outputs. Pi ARM64
integration and actual external-output observations remain separate
qualification evidence.
