## Cutover rule

None of these PRs was merged or modified during this audit. No new branch or
PR was created. Hardware-facing PR checks that are named `hardware-probe` or
`Host assignment and software-probe contract` remain software probes unless
the test actually uses the target board and instruments. The StageLaser
momentary-toggle interlock is an explicit safety blocker. Keep Project ACL
disabled and all physical outputs inhibited until the applicable software,
deployment, and hardware evidence is separately accepted.
